About

This mini-web app helps you generate peer configuration files for WireGuard tunnels. It is intended for use with WireGuard networks that don't offer you another more convenient way to generate peer configs.

For the most secure operation, delete secret (private / shared) keys from this app after you've exported their configuration.

Limitations:

  • This app cannot help with IPv6 tunnel network addressing, or with IPv4 subnets larger than /24.
  • This app does not support having multiple remote networks (e.g. an IPv4 and IPv6 network both accessible via the same tunnel).
  • Most input fields are not validated.
